# Frame Home

A calm home screen for a Samsung The Frame TV, built as a [TizenBrew](https://github.com/reisxd/TizenBrew) app module.

- A glass arch with the clock and a sun or moon that moves with the time of day
- A scrolling row of apps (Netflix, YouTube via TizenTube, Spotify, Viu, mewatch), opened with OK
- Soft teal-to-indigo landscapes, one for each part of the day, fading into each other
- Live Singapore temperature from data.gov.sg (no key needed)
- HDMI and volume buttons sent through the TV's own remote-control channel
- A Setup check screen that shows what the TV allows

## Install

In TizenBrew, open the module manager, add a GitHub module and type the newest pinned version, for example `kforkylie/frame-home@0.2.3`. Pinned versions load straight away; the unpinned name can be served stale by the CDN for hours.

## Remote

Left and right move along the apps, OK opens. Down goes to HDMI, volume and Setup check, Up comes back.

Nothing in this module changes TV settings. It only opens apps and sends remote-control keys.
